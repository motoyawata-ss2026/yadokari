ヤドカリくん サポート

最終更新日：2026年11月5日

ヤドカリくんは、持ち家を貸す・売る・住むの比較と、家賃・住宅ローンの試算ができるアプリです。 AIによる適正家賃の分析、金利が上がったときの返済の試算、借り方（固定・変動・借り換え・頭金）の比較、持っている物件全部の収支のまとめができます。

よくある質問

無料と有料（プレミアム）の違いは？

無料でも、物件2件までの登録・家賃・ローン（借り方を比べるを含む）・1物件のシミュレーションを使えます。AI分析は月3回まで（インストールから1ヶ月は月10回まで）です。 3件目からの物件の登録と全物件シミュレータは、インストールから1ヶ月は無料で使え、その後はプレミアムの機能です。 プレミアム（月額 ¥300・年額 ¥3,000）では、AI分析が月50回まで使えます。回数は、お支払いの日から1ヶ月ごとに数えます（無料プランで使った回数とは別です）。

無料期間やプレミアムが終わったら、登録した物件はどうなる？

データは消えません。物件が2件より多いときは、先に登録した2件のほかに鍵が付き、開けなくなります（削除はできます）。 プレミアムに加入し直せば、すぐに前と同じように使えます。

データはどこに保存される？

物件・ローンなどのデータは、お使いの端末と、ご自身の iCloud（同じ Apple ID の iPhone・iPad で共有）にだけ保存されます。開発者が見ることはできません。

iPhone と iPad の両方でプレミアムを使うには？

両方の端末で、同じ Apple ID で「Appleでログイン」してください（設定 → アカウント）。 ログインせずに購入したあとでログインしても、購入は引き継がれます。

購入したのにプレミアムにならない・機種を変えたときは？

設定 → サブスクリプション の「購入を復元」を押してください。二重に請求されることはありません。

解約するには？

アプリの 設定 → サブスクリプション →「サブスクリプションの管理」、または iOS の設定アプリ → Apple ID → サブスクリプション から解約できます。 解約しても、料金を払った期間の終わりまではプレミアムのまま使えます。

計算はどのくらい正確？

一般的な前提で計算した概算です。実際の返済額・税金・家賃は、金融機関・税務署・不動産会社などでご確認ください。
