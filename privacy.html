プライバシーポリシー

最終更新日：2026年10月4日

本プライバシーポリシーは、ヤドカリくん（以下「本アプリ」）における利用者情報の取り扱いについて定めるものです。

1. 収集する情報

本アプリは、以下の情報を取り扱います。

  • AI分析のために送る物件の情報：所在地、物件の種別、広さ、築年数、最寄り駅と徒歩分数、間取り、階数、向き、設備、リフォームの有無、省エネ性能、現在の家賃など。 AI分析を実行したときだけ送信し、分析の結果を返すためにのみ使います。本アプリのサーバーには保存しません。
  • ユーザーID と AI分析の利用回数：アプリを初めて起動したときに、個人を特定しないユーザーIDを自動で発行し、月ごとの AI分析の利用回数を数えるために使います。
  • Appleでログインした場合：Apple が発行する利用者の識別子と、メールアドレス（Apple の「メールを非公開」を選んだ場合は、Apple の転送用アドレス）。 ログインは任意で、ログインしなくてもすべての機能を使えます。
  • 購入の情報：プレミアムプランの購入・更新・解約の状態。支払いは Apple が行い、本アプリがクレジットカードなどの支払い情報を受け取ることはありません。

氏名・電話番号・利用者の住所・位置情報・広告用の識別子は収集しません。また、利用状況を解析するツールは使っていません。

2. 物件・ローンなどのデータの保存場所

登録した物件・ローン・費用・売却の計画・AI分析の結果は、お使いの端末と、利用者ご自身の iCloud（同じ Apple ID の iPhone・iPad で共有するため）にのみ保存されます。 本アプリの開発者が、これらのデータを見ることはできません。

3. 情報の利用目的

  • AI分析などのアプリの機能の提供
  • AI分析の利用回数の管理と、プレミアムプランの提供
  • 不具合の調査・修正と、お問い合わせへの対応

4. 利用している外部のサービス

本アプリは、機能を提供するために以下のサービスを利用しています。サーバーが日本国外（主に米国）にあるサービスを含みます。

  • Supabase（Supabase Inc.）：ユーザーID・ログインの管理、AI分析の利用回数の保存
  • Claude API（Anthropic, PBC）：AI分析（物件の情報を送り、適正家賃の分析結果を受け取ります）
  • RevenueCat（RevenueCat, Inc.）：プレミアムプランの購入状態の管理
  • 不動産情報ライブラリ API（国土交通省）：AI分析の参考データの取得（都道府県と物件の種別のみを送ります）
  • Apple：App Store での購入、iCloud でのデータの共有、Appleでログイン

各サービスにおける情報の取り扱いについては、それぞれのプライバシーポリシーをご確認ください。

5. 第三者への提供

本アプリは、上記の外部のサービスへの送信と、以下の場合を除き、取り扱う情報を第三者に提供しません。

  • 法令に基づく開示が必要な場合
  • 人の生命・身体・財産の保護のために必要な場合

6. 情報の削除

  • 端末のデータは、アプリを削除すると消去されます。iCloud のデータは、iOS の設定の iCloud の管理から削除できます。
  • Appleでログインしている場合は、アプリの 設定 → アカウント → 「アカウントを削除」 から、ログインの情報・AI分析の利用回数・購入の記録を削除できます。
  • それ以外の削除のご希望は、下記のお問い合わせ先までご連絡ください（設定画面に表示されるユーザーIDを添えてください）。
  • プレミアムプランの解約は、iOS の設定アプリ → Apple ID → サブスクリプション から行えます。

7. 子どものプライバシー

本アプリは13歳未満の方を対象としておらず、意図的に13歳未満の方の情報を収集することはありません。

8. プライバシーポリシーの変更

本ポリシーは必要に応じて改定することがあります。 重要な変更がある場合は、アプリ内またはこのページにてお知らせします。
